# Child-Learning Cycle

## Goal
Operationalize the learning pattern:
Observe -> Understand -> Deconstruct -> Imitate Safely -> Practice -> Compare -> Critique -> Abstract -> Synthesize -> Create -> Validate -> Remember

## 1. Observe
Collect permitted source material with provenance and context.

## 2. Understand
Identify intent, audience, context, medium, production conditions, and likely function.

## 3. Deconstruct
Break a work into transferable decisions:
- composition
- hierarchy
- camera/viewpoint
- lens/focus
- light
- material behavior
- color
- sequence
- garment logic
- pacing
- typography
- narrative
- commercial purpose

## 4. Imitate safely
Practice an abstract principle, not a creator's signature expression.

Allowed example:
"Practice motivated side lighting with controlled negative fill."

Disallowed learning target:
"Copy the exact visual signature of a living photographer."

## 5. Practice
Generate controlled exercises with one or a few variables changed.

## 6. Compare
Compare intended principle against result and baseline.

## 7. Critique
Identify causality, preservation, quality, originality, context, and execution failures.

## 8. Abstract
Convert repeated evidence into a scoped hypothesis.

## 9. Synthesize
Combine compatible principles from different domains.

## 10. Create
Apply internalized principles to a new objective without reproducing the training/source artifact.

## 11. Validate
Use QC, similarity/copy-risk checks, world-model constraints, rights rules, and human review policy.

## 12. Remember
Store outcome in episodic/practice memory and create a learning candidate if evidence justifies it.

## Promotion rule
Practice success is not sufficient for universal promotion. Repetition, diversity of evidence, context scope, contradiction review, and approval remain required.
