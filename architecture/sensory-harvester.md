# Sensory Harvester Architecture

## Purpose
Provide the Creative Organism with a controlled, private sensory intake system for fashion and visual culture.

## Inputs
- registered fashion websites
- campaign/editorial sites
- photographer/designer portfolios
- permitted social/discovery sources
- image sources
- video sources

## Pipeline
Source Registry
-> Change Detection
-> Collector Adapter
-> Asset Discovery
-> Rights/Role Classification
-> Deduplication
-> Image/Video Analysis
-> Observation Extraction
-> Learning Candidate
-> Governed Promotion

## Source authority
- primary/official
- credible secondary
- discovery/repost

Discovery repetition must never be counted as independent evidence when it is the same underlying asset.

## Image analysis
Possible observations:
- garment/product
- pose
- composition
- camera distance
- lens behavior
- lighting
- environment
- material response
- color
- post
- crop/platform
- visual hierarchy

## Video intelligence
Analyze:
- shot boundaries
- camera motion
- subject/model motion
- fabric motion
- edit rhythm
- shot duration
- lighting changes
- continuity
- color progression
- narrative sequence
- sound/image relation when accessible

## Storage
When authorized and technically appropriate:
- store image/asset + source record

Otherwise:
- retain URL, metadata, hashes, analysis, and permitted derived observations

## Private-only
The sensory system is backend/internal. Ordinary users do not see source-harvesting methodology or global research registry.
