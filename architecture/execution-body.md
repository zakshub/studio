# Creative Organism — Execution Body

## Purpose
Separate cognition from action.

The intelligence layer decides what should happen. The execution body carries it out through replaceable tools.

## Body systems
- Figma/design execution
- deterministic image processing
- image generation/editing
- video generation/editing
- website/source acquisition
- database/object storage
- export/delivery
- code/runtime services

## Contract
Cognition produces:
- objective
- constraints
- production plan
- capability request
- QC plan

Executor Gateway chooses an eligible adapter from capability evidence.

Execution returns:
- output assets
- diagnostics
- timing/cost metadata internally
- no customer-facing provider identity by default

## Rule
Tools are muscles, not the brain.
A provider/tool failure must not mutate the organism's values or canonical knowledge.
