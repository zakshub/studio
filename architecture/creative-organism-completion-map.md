# Creative Organism Completion Map

## Functional goal
Build a governed creative intelligence that can observe, remember, reason, practice, synthesize, decide, act through tools, verify itself, and learn under human oversight.

This document uses "conscious" and "subconscious" as system-design metaphors.

## Subconscious / value layer
Status: IMPLEMENTED IN ARCHITECTURE + RUNTIME GATES

Includes:
- truth over confident invention
- source integrity
- preservation priority
- rights awareness
- neutral universal core
- client specialization without contamination
- evidence before canonical learning
- no expert signature-style copying
- human approval for governed promotion/high-risk decisions
- private-methodology boundary

## Conscious / deliberative layer
Status: IMPLEMENTED AS RUNTIME BOOTSTRAP

Cycle:
ORIENT -> ATTEND -> FRAME -> RECALL -> DIVERGE -> SIMULATE -> CONSULT -> CRITIQUE -> CONVERGE -> DECIDE -> EXECUTE -> VERIFY -> REFLECT -> LEARN

Includes:
- attention
- expert-council selection
- metacognition
- uncertainty flags
- decision records
- curiosity/research questions
- creative divergence

## Memory
Status: PARTIAL RUNTIME

Implemented:
- canonical semantic memory
- runtime memory records
- governed learning candidates
- decay/deprecation
- task state
- brain revision snapshots in-process

Still required:
- full project/episodic/procedural persistence across all workflows
- persistent semantic/vector index
- durable revision snapshots outside process memory

## Expert intelligence
Status: RUNTIME AGGREGATOR IMPLEMENTED; KNOWLEDGE POPULATION INCOMPLETE

Implemented:
- 50-person canonical roster
- expert profile schema
- expert councils
- council selector
- aggregator preserving expert identity and disagreements
- four evidence-ready first-pass profiles

Still required:
- evidence packs and validated profiles for remaining 46
- activate profiles after validation
- automated profile ingestion/indexing

## Sensory system
Status: BOOTSTRAP IMPLEMENTED

Implemented:
- source registry
- authority/rights metadata
- change fingerprints
- normalized observations
- structured video timeline/shot analysis contract
- coverage/bias monitor

Still required:
- production website crawler
- permitted social adapters
- image-understanding model integration
- real video decoder/keyframe/shot pipeline
- source storage/object storage
- automatic observation persistence

## Practice / child-learning cycle
Status: PLANNER IMPLEMENTED

Cycle:
OBSERVE -> UNDERSTAND -> DECONSTRUCT -> IMITATE PRINCIPLE -> PRACTICE -> COMPARE -> CRITIQUE -> ABSTRACT -> SYNTHESIZE -> CREATE -> VALIDATE -> REMEMBER

Implemented:
- controlled practice plans
- fixed vs controlled variables
- evaluation dimensions
- failure-to-learning bootstrap

Still required:
- connect practice sessions to real executors
- automatic candidate generation
- QC comparison
- repeated-session performance history

Implemented:

- multidimensional coverage monitoring

Still required:

## Body / execution
Status: GATEWAY BOOTSTRAP IMPLEMENTED

Implemented:

- execution-body architecture

Still required:

## Background / subconscious processing
Status: SERVICE + SCHEDULER BOOTSTRAP IMPLEMENTED

Implemented:
- repeated-observation clustering
- learning-candidate suggestion
- simple scheduler
- curiosity generation
- novelty checks

Still required:
- durable worker process
- scheduled jobs in deployment
- weak-signal detection across time
- trend windows and temporal baselines

## Completion definition
The organism is functionally complete for MVP when:
1. sensory inputs enter automatically
2. observations persist
3. relevant knowledge and experts are retrieved
4. cognition creates alternatives and selects a plan
5. executor gateway performs the work
6. QC evaluates the result
7. provenance is stored
8. failures feed governed learning
9. background synthesis creates candidates
10. humans retain approval where policy requires it
