# Creative Organism Architecture

## Purpose
Extend Studio Brain from static knowledge into a governed adaptive creative intelligence system.

This is an engineering metaphor. The system is not claimed to be literally conscious.

## Functional layers

### Deliberative layer
Goal management, attention, planning, simulation, critique, choice, and escalation.

### Background synthesis layer
Pattern detection, clustering, weak signals, contradiction detection, novelty checks, and scheduled synthesis.

### Meta-intelligence
Selects which specialist intelligence to consult and resolves cross-disciplinary tradeoffs.

### Expert intelligences
Structured knowledge profiles derived from expert public work, interviews, methods, and documented practice. Experts remain distinct rather than being flattened into one style.

### World model
Physical and contextual models for camera, light, material, human movement, garment behavior, culture, environment, color, and production.

### Memory
- semantic
- episodic
- procedural
- project
- task/working memory

### Sensory system
Controlled ingestion and analysis of websites, images, videos, campaigns, social/discovery sources, and research.

### Learning engine
Observe -> normalize -> compare -> validate -> promote/reject.

### Quality / immune layer
QC, source rights, bias checks, contamination detection, hallucination safeguards, security and poisoning resistance.

### Execution layer
Replaceable tools/providers/models.

### FashionOS surface
Simple customer experience that exposes outcomes, not methodology.

## System principles
- neutral by default
- specialization without contamination
- evidence before promotion
- uncertainty is explicit
- strong forgetting/deprecation hygiene
- internal complexity, external simplicity
