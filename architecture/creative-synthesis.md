# Original Creative Synthesis

## Goal
Create new directions by recombining internalized principles across domains while preserving context, originality, and physical coherence.

## Inputs
- objective
- values
- task constraints
- world model
- retrieved knowledge
- current observations
- relevant memories
- selected expert councils
- cultural/market context
- novelty requirements
- approval policy

## Synthesis stages
1. Problem framing
2. Principle selection
3. Controlled tension selection
4. Divergent concept generation
5. Cross-domain recombination
6. Counterfactual simulation
7. Similarity/copy-risk check
8. Context and physical-world check
9. Self-critique
10. Convergence
11. Decision record
12. Human approval when required

## Controlled tensions
Examples:
- refined / raw
- traditional / contemporary
- stillness / motion
- soft / hard
- intimate / monumental
- ornate / restrained
- familiar / unexpected

These are reasoning devices, not mandatory aesthetics.

## Originality rule
A concept should be explainable through general principles and task context rather than "because a specific creator did it."

## Output
A CreativeDecision contains:
- concept
- objective fit
- principles used
- constraints preserved
- unresolved risks
- novelty assessment
- required approvals
- execution requirements
