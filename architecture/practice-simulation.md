# Practice and Simulation Engine

## Purpose
Turn passive knowledge into usable skill through controlled exercises and counterfactual comparison.

## Practice session
A session defines:
- target principle
- source/evidence IDs
- skill domain
- baseline
- controlled variables
- fixed variables
- candidate count
- evaluation dimensions
- similarity/copy-risk threshold
- human review policy

## Modes
### Principle drill
Practice one transferable principle.

### Constraint drill
Solve the same objective under different constraints.

### Counterfactual
Compare alternatives such as camera distance, lighting family, environment, pacing, or material treatment.

### Failure repair
Reproduce a known failure condition and test remediation strategies.

### Cross-domain synthesis
Combine principles from two or more councils.

## Evaluation
Each candidate is compared for:
- objective fit
- constraint compliance
- physical coherence
- source preservation when applicable
- originality
- context suitability
- execution quality
- cost/latency where relevant

## Memory output
Practice generates:
- practice episode
- failure observations
- successful strategy observations
- scoped learning candidates
- benchmark cases when useful

## Safety
No practice result becomes a public/customer asset without passing the normal task/QC/approval pipeline.
