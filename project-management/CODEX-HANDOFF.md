## 2. Canonical architecture principle

**FashionOS owns intelligence/workflow; models are replaceable workers.**

The system should behave like an organism:
- brain = knowledge, values, memory, reasoning, creativity, expert intelligence
- body/hands = executors, models, Figma, source collectors, image/video tools
- immune/error system = QC, preservation verification, provenance, approval gates

Human approval remains authoritative where policy requires it.

## 13. Image-production doctrine

For imagery tasks:
1. classify task
2. classify source roles
3. extract hard locks / soft locks / allowed changes
4. choose reality class
5. retrieve relevant intelligence
6. build production plan
7. choose execution strategy
8. execute
9. run preservation + forensic anti-AI QC
10. store provenance
11. request human approval if required
12. create learning candidates from outcomes

Hard-lock examples:
- face identity
- age appearance
- skin tone
- garment silhouette
- neckline
- sleeves
- embroidery placement
- fabric character
- trouser details
- props / scene details when specified

Critical QC:
Any critical preservation / physical causality / anatomy / camera-light score <= 2/5 requires rework.

Anti-AI defaults:
- believable skin
- believable anatomy
- believable fabric behavior
- motivated lighting
- coherent shadows
- coherent optics
- no pasted/cutout look
- no arbitrary cinematic effect
- no fake perfect environment unless task requires it

## 14. Recent image reasoning example

A real street motorcycle portrait was analyzed using the brain.

Decision:
- keep identity/body/pose/bike/street context
- preserve Urdu signage
- selectively remove distracting litter rather than sterilizing environment
- reduce background competition
- refine existing daylight rather than inventing fake lighting
- preserve natural skin/body
- use documentary-editorial treatment
- avoid artificial bokeh and AI reconstruction

A later creative restyle turned the scene into a bike-model shoot.

This illustrates the intended distinction between:
- strict existing-image treatment
- creative re-generation / restyle

Codex should preserve that distinction in product behavior.
