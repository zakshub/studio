# Decision Log

## D-001 — Studio Brain is brand-agnostic
Decision: No brand identity is canonical. Client/workspace context is runtime-only unless independently generalized and promoted.

## D-002 — Studio Brain is provider-agnostic
Decision: Gemini, OpenAI, local models, deterministic tools, and future executors are replaceable workers.

## D-003 — Methodology is private
Decision: Ordinary users do not see repo structure, prompts, routing, provider details, internal rules, or learning mechanics.

## D-004 — No global model winner
Decision: Routing is capability-specific and evidence-driven.

## D-005 — Research does not auto-promote
Decision: Research creates candidates; canonical intelligence requires governed promotion.

## D-006 — Existing assets are first-class
Decision: FashionOS supports new generation, existing-image treatment, and website-source treatment.

## D-007 — Primary and secondary websites have different authority
Decision: Primary authorized sources may enter production treatment; secondary sources are reference intelligence by default.

## D-008 — Preservation beats aesthetics
Decision: A visually attractive result that violates hard locks fails.

## D-009 — API before full Figma redesign
Decision: Freeze domain/API contract before designing the complete new UI so screens map to real system states.

## D-010 — Frontend says FashionOS, not provider
Decision: Ordinary UI communicates FashionOS outcomes, not Gemini/OpenAI/GitHub methodology.
