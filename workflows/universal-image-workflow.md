# Universal Image Workflow

## Phase 1 — Intake
Identify:
- user objective
- source images and which one is the edit target
- references vs identity/outfit/environment locks
- final platform
- requested crop/aspect
- whether the user wants preservation or redesign

## Phase 2 — Classification
Select:
- task mode
- photographic genre
- reality class
- polish level
- delivery provenance

## Phase 3 — Locks
Create:
- HARD LOCKS
- SOFT LOCKS
- UNLOCKED creative variables

Never infer that "make it better" authorizes redesign.

## Phase 4 — Protocol selection
Read relevant repo files and select only the needed production protocols.

Typical stack:
- intent + narrative
- subject
- environment
- camera
- lens
- lighting
- composition
- color/texture
- post
- delivery
- QC

Add specialized reality controls:
- material/garment/skin/hair
- controlled imperfection
- provenance
- source preservation
- anti-AI

## Phase 5 — Production specification
Before execution, decide:
- camera viewpoint/distance
- focal length/aperture/focus
- shutter/motion
- lighting source/motivation/ratio
- material behavior
- environment depth
- grade/color pipeline
- post intensity
- expected capture/delivery artifacts

## Phase 6 — Execution
Generate/edit without violating locks.

## Phase 7 — QC
Run:
1. identity/preservation check
2. anatomy/pose/hand check
3. garment/material check
4. camera/lens perspective check
5. lighting/shadow/highlight check
6. depth/focus/bokeh check
7. environment/scale/reflection check
8. color/grade check
9. texture/imperfection check
10. delivery/provenance check
11. anti-AI artifact check

## Phase 8 — Report
Use:
- Mode
- Reality class
- Repo files/rules used
- Hard locks
- Allowed changes
- Applied work
- Verification
- Remaining issues
