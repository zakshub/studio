# Studio Image Production Intelligence

Canonical repository for universal image generation, editing, retouching, grading, photographic realism, anti-AI realism, source-preservation, post-production, delivery, and QC workflows.

## Operating contract
For every imagery task, use this repository as the canonical production brain before generating or editing.

Required sequence:
1. Classify the task mode.
2. Select the photographic reality class.
3. Read the relevant production intelligence and realism files.
4. Declare hard locks and allowed changes.
5. Build the camera/lens/light/material/color/post pipeline.
6. Execute.
7. Run preservation + forensic anti-AI QC.
8. Report exactly what repo knowledge was used, what changed, what was preserved, and what passed/failed verification.

## Scope
This is not fashion-only. It covers:
- new image generation
- existing image editing
- strict preservation enhancement
- retouching
- relighting
- grading and LUT/look development
- face-led model creation
- outfit-led model creation
- fashion/editorial/lifestyle
- portraiture
- documentary
- product/commercial
- cinematic stills
- mobile/social photography realism
- delivery/compression-aware imagery

## Relationship to the 170-Protocol Manual
The supplied Production Intelligence Engine 170-Protocol Manual remains the master production architecture. This repo extends it with deeper photographic-reality controls that were under-specified in the original system: photographic reality class, causal reality, garment physics, material response, skin/hair reality, camera distance, controlled imperfection, capture-to-delivery provenance, source-preservation hard locks, platform/compression reality, and forensic anti-AI QC.

## Approval principle
A result is not approved because it is attractive. It is approved only when it is coherent with the selected production intent and can be explained as a plausible capture/edit/delivery chain for the selected reality class.
