# Production Intelligence Engine — 170 Protocol Summary

This file preserves the operating structure of the supplied 170-Protocol Manual.

## Purpose
The manual is a production decision engine, not a decorative checklist. It moves from concept to production-quality output for AI imagery, real shoots, cinematic frames, posters, product visuals, portraits, web heroes, and social assets.

## Universal production formula
- Concept decides purpose.
- Intent decides viewer reaction.
- Research defines benchmark.
- Feasibility protects execution.
- Subject, environment, camera, lens, light, composition, color, texture, and atmosphere create the visible result.
- Post-production, delivery, quality control, and learning turn the result into a usable product.

## Protocol layers
### A. Concept + Intent — 1–10
Input interpretation, user intent, problem definition, output purpose, success criteria, audience, emotional objective, visual intent, reality level, concept strength.

### B. Strategy + Creative Direction — 11–20
Creative brief, core message, narrative moment, genre/world, mood, tone, art direction, aesthetic discipline, style boundary, originality.

### C. Research + Reference — 21–30
Reference collection, deconstruction, fusion, category scan, visual benchmark, camera reference, lighting reference, color reference, composition reference, reference risk.

### D. Production Feasibility — 31–40
Feasibility, budget reality, time, resources, technical risk, visual risk, complexity, priority, backup plan, scope control.

### E. Subject / Character / Object — 41–50
Subject selection/priority, psychology, facial expression, eye direction, body language, pose, pose realism, hand logic, subject consistency.

### F. Environment + Set — 51–60
Location logic, environment design, set dressing, background depth, foreground layer, surface materials, practical environment light, environmental story, spatial realism, consistency.

### G. Camera System — 61–70
Camera selection/character, sensor format, recording format, codec, bit depth, resolution, color profile, monitoring LUT, camera settings.

### H. Lens + Optical — 71–80
Lens psychology, focal length, lens type, depth of field, focus strategy, perspective control, bokeh, optical texture, filters, lens realism check.

### I. Lighting Intelligence — 81–100
Lighting architecture, key, feathering, modifier, diffusion, spill control, fill, negative fill, rim/back light, hair/shoulder light, background light, snoot/gobo/pattern, practicals, ratio, color temperature, shadow design, highlight control, light motivation, realism, failure diagnosis.

### J. Composition + Motion — 101–110
Composition, hierarchy, shot type, blocking, camera movement, frame rate, shutter, aspect ratio, crop, platform framing.

### K. Color + Texture + Atmosphere — 111–120
Exposure, contrast, palette, color science, LUT, film emulation, shadow color, highlight color, texture, atmosphere.

### L. AI Image Production — 121–130
Prompt translation/structure, negative prompts, artifact control, model consistency, scene consistency, variation, inpainting, upscale, AI realism check.

### M. Real Shoot Execution — 131–140
Shot list, lighting diagram, gear, location scout, call sheet, crew, on-set QC, backup, continuity, safety.

### N. Post-Production — 141–150
Selection, retouching, compositing, VFX, base correction, creative grade, grade matching, sharpening/noise, final retouch QC, master export.

### O. Product-Ready Delivery — 151–160
Platform delivery, responsive crop, typography, layout, brand consistency, accessibility, client review, versioning, revision, handoff.

### P. Quality Control + Learning — 161–170
Quality score, failure diagnosis, production realism, visual coherence, emotional accuracy, technical accuracy, commercial readiness, rework decision, archive, learning feedback.

## Lighting standard
Every light must have:
- placement
- height/angle
- modifier
- diffusion
- spill control
- fill/negative fill logic
- rim/background/practical purpose
- ratio/power logic
- expected shadow/highlight
- reason for existence

Specify camera body/sensor/codec/bit depth/profile/LUT, lens/aperture/filter/focus/distance, lighting diagram, location conditions, shot list, on-set QC, and data management.

## QC dimensions
Concept clarity, emotional accuracy, subject direction, environment logic, camera/lens realism, lighting architecture, composition/hierarchy, color/grade, texture/atmosphere, artifact control, post finish, delivery readiness.
