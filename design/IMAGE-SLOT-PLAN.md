# FashionOS v2 — Initial Image Slot Plan

Purpose: define where generated/reference imagery is required before Figma high-fidelity execution.

## Dashboard
- Hero / featured visual: 16:7 wide editorial crop
- Recent asset cards: 4:5
- Recent video card: 16:9 thumbnail
- Small source previews: 1:1 or 4:5

## Source Intake
- Source thumbnails: original aspect ratio inside fixed preview shell
- Duplicate comparison: 4:5 paired
- Quality inspection: zoomable original

## Website Import
- Discovered fashion asset grid: 4:5 default
- Campaign landscape preview: 16:9
- Product/ecommerce preview: original ratio

## Collection Studio
- Collection look card: 4:5
- Look detail hero: 4:5 or 3:4
- Material/detail crop: 1:1
- Comparison views: consistent matching aspect ratio

## Design Intelligence
- Silhouette options: 3:4
- Color/motif detail: 1:1
- Full-look variation: 4:5

## Visualization Studio
- Main work canvas: adaptive, default 4:5
- Reference rail: original ratio thumbnails
- Compare outputs: matching dimensions
- Campaign landscape option: 16:9
- Social vertical option: 9:16

## Existing Image Treatment
- Before/after pair: exact same source aspect ratio
- Detail comparison crops: 1:1
- Full-resolution inspection: source dimensions

## Campaign Studio
- Campaign hero: 16:9 or 3:2
- Fashion portrait: 4:5
- Social vertical: 9:16
- Story sequence thumbnails: 9:16 / 4:5 depending output

## Assets Library
- Masonry uses preserved asset ratios
- Standard list thumbnail fallback: 4:5
- Video: 16:9 or source ratio

## Review & Approval
Never crop the evidence view in a way that hides preservation changes.
- source vs result: exact matching ratio
- zoom/detail: 1:1 crop linked to same coordinates

## Figma production rule
For high-fidelity screens:
1. define exact frame dimensions first
2. generate/select image for that slot and crop
3. place directly where practical
4. if direct placement is unavailable, place the exact-size asset beside the frame with a clear slot label
