# Focused Visual Research Report

Access date: 2026-10-08
Repository: zakshub/studio

Reviewed five distinct campaign datasets against existing Studio rules EF 001 through EF 028. One scoped rule was promoted. Four observations were deferred because they were one off, overlapped existing intelligence, or lacked technical evidence.

## Reviewed datasets

1. Moncler Have a Puffy Summer 2026. New but weak: sculptural set objects echo garment volume and collection colors. Not promoted because only one campaign supports it.
2. Valentino Spring Summer 2026 Fireflies. Exception: an arrested pre fall pose uses stillness to express suspense. Not a replacement for EF 012 motion based garment validation.
3. Phoebe Philo Collection D 2026. New but weak: repeated red typography unifies portraits, product still life, animal imagery, texture, and shadow frames. Not promoted because evidence is one campaign and overlaps existing fragment based continuity.
4. Fendi Fall Winter 2026 to 2027. New but weak: mirrors create a second spatial plane inside the frame. Not promoted because evidence is one campaign and partly overlaps EF 021.
5. Balenciaga A New York Minute 2026. High value: the same hero bag connects the main story and a film within the film before a production reveal. Promote CF 001 Nested narrative anchor continuity.
